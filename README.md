# BELL 카드게임 Stage 8 — 완성도 및 재접속

이번 단계에서 추가된 기능

- 새로고침 후 기존 방 자동 재접속
- Firebase 연결 상태 실시간 표시
- 게임 로그 최근 12개 표시
- 벨, 카드 뽑기, 버리기, 턴, 결과 효과음
- 효과음 켜기/끄기

- 핵심 규칙 모달

## 재접속

같은 브라우저에서 새로고침하면 저장된 방 코드와 익명 UID를 확인해
기존 방에 자동으로 다시 들어갑니다.

시크릿 창을 완전히 닫으면 익명 로그인 정보가 사라질 수 있습니다.
