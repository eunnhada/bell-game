# BELL 카드게임 Stage 11 — 대기실 완성

## 추가된 기능

- 일반 플레이어 준비 / 준비 취소
- 방장은 자동 준비 상태
- 전원이 준비해야 게임 시작 가능
- 방장이 플레이어 내보내기 가능
- 2대2·3대3 팀 다시 섞기
- 팀을 바꾸면 전원이 다시 준비
- 게임 모드를 바꾸면 준비 상태 초기화
- 입장 순서 기반 A팀·B팀 임시 표시
- 중복 닉네임 입장 차단
- 강퇴된 사용자는 자동으로 메인 화면 이동

## 적용 방법

1. 압축을 풉니다.
2. 기존 `BELL-GAME` 폴더에 전부 덮어씁니다.
3. Live Server에서 새 방으로 테스트합니다.
4. 이상 없으면 GitHub에 올립니다.

```powershell
git add .
git commit -m "대기실 준비와 강퇴 기능 추가"
git push
```

## 테스트 순서

1. 방장 방 생성
2. 일반 플레이어 1명 이상 참가
3. 일반 플레이어가 준비하기
4. 전원이 준비해야 게임 시작 버튼 활성화
5. 준비 취소 시 다시 비활성화
6. 팀전 선택 후 팀 다시 섞기
7. 방장이 다른 플레이어 내보내기
8. 같은 닉네임으로 입장 시 차단 확인
