# BELL v26 — 결과 카드 공개 및 내 차례 알림 강화

## 수정
- 제출할 때 선택 카드의 id, 색상, 숫자를 결과 데이터에 복사 저장
- 모든 참가자 기기에서 상대 카드 결과를 동일하게 표시
- 기존 방 데이터는 손패 조회 방식으로 호환
- 빨강/노랑/초록/파랑 결과 카드 배경색 적용
- 컴퓨터와 모바일 모두 결과 패널 내부 스크롤 지원
- 내 차례 알림을 3단 상승음 + 추가 고음으로 강화
- 내 차례 진동 패턴 강화
- 게임판 금색 점멸 효과 추가
- 효과음 ON 시 강화된 내 차례 음으로 테스트

## 적용
```powershell
git add .
git commit -m "v26 결과 카드 공개와 턴 알림 강화"
git push
```
