# BELL 포카드 규칙 추가본

## 포카드 규칙

서로 다른 네 가지 색의 같은 숫자 카드 4장을 제출하면 포카드입니다.

예:

- 빨강 3
- 노랑 3
- 초록 3
- 파랑 3

위 조합은 `포카드 3`입니다.

## 승패 우선순위

1. 포카드
2. 일반 숫자 조합

포카드는 숫자 합이 얼마든 모든 일반 조합을 이깁니다.

예:

- 포카드 1: 합계 4
- 일반 같은 색 조합: 합계 34

이 경우에도 포카드 1이 승리합니다.

## 포카드끼리 비교

포카드가 여러 명이면 카드 숫자가 높은 포카드가 이깁니다.

- 포카드 8 > 포카드 5
- 같은 숫자의 포카드끼리는 동점

## 다른 규칙

- 개인전 카드 1장 제출 가능
- 팀전 카드 1장 제출은 희생
- 2장 이상 일반 조합은 같은 색 또는 같은 숫자
- 내 라이프 표시
- 채팅 및 게임 연출
- 최종 결과 유지
- 다시하기 시 같은 방 대기실 복귀

## 적용 방법

1. 압축을 풉니다.
2. 기존 `BELL-GAME` 폴더에 전부 덮어씁니다.
3. Live Server를 중지했다가 다시 실행합니다.
4. 일반 창과 시크릿 창에서 Ctrl + F5
5. 반드시 새 방으로 테스트합니다.
