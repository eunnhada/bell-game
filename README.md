# BELL v29 — 안정 원본 기반 12개 기능 추가

이 버전은 사용자가 다시 첨부한 정상 작동 v24 파일을 기준으로 만들었습니다.

카드 가져오기 → 손패 5장 → 직접 또는 자동 버리기 로직은 원본 그대로 유지했습니다.

## 적용 기능

1. 벨 실패
- 최고점이 아닌 플레이어가 벨을 누르면 그 사람만 라이프 2개 감소
- 다른 최고점·최저점 플레이어는 라이프 유지

2. 손패 간격
- 카드 간격 확대
- 터치 영역과 선택 우선순위 보강

3. 라운드 설정
- 방장이 3라운드 또는 5라운드 선택
- 게임 시작 로직과 분리하여 저장

4. 나가기 확인
- 예/아니오 확인 후 나가기

5. 나간 플레이어
- 턴 순서·손패·제출 목록에서 제거
- 해당 플레이어 턴이면 즉시 다음 플레이어로 진행
- 로그에서 ‘알 수 없음’ 대신 기존 닉네임 표시

6. 내 차례 효과음
- 첫 턴을 포함해 내 차례마다 재생

7. 카드 이동 연출
- 카드 획득 시 획득한 플레이어 쪽으로 이동하며 페이드아웃
- Firebase 카드 로직은 변경하지 않음
- 이전 상태와 현재 상태를 비교해 연출

8. 카드 쓱 효과음
- 더미와 오픈 카드에 서로 다른 쓱 효과음

9. 배경음악
- 게임 중 간단한 루프 BGM
- 🎵 버튼으로 ON/OFF

10. 마지막 5초
- 내 턴과 상대 턴 모두 테두리가 빨간 마지막 5초에 매초 효과음

11. 라운드 승점
- 1위 2점
- 2위 1점
- 나머지 0점
- 같은 라이프면 같은 순위 점수
- 최종 순위는 누적 승점 우선
- 팀전은 팀의 남은 라이프 합계로 라운드 점수 계산

12. 세트 결과 카드
- 빨강 7, 초록 3처럼 색상명과 숫자를 함께 표시
