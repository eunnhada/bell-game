# BELL Stage 14 Mobile Edition

최신 포카드 버전을 기준으로 모바일 전용 게임 화면을 적용했습니다.

## 모바일 변경 사항

- 휴대폰 게임 화면의 세로 스크롤 최소화
- 상대 플레이어 영역 축소
- 상대 목록 가로 스크롤
- 오픈 카드·더미·벨을 한 줄에 배치
- 내 카드 영역 우선 배치
- 내 라이프와 닉네임을 작고 선명하게 표시
- 손패 크기를 화면 폭에 자동 조절
- 로그·채팅 기본 접힘
- 로그·채팅 버튼으로 펼치기
- 채팅 탭을 누르면 자동 확장
- 모바일 가로 화면 전용 3단 배치
- 결과 화면은 게임판 위 팝업 형태
- 카드를 0.45초 길게 누르면 확대 보기
- 아이폰 안전 영역과 홈바 여백 대응

## 유지되는 기능

- 포카드 최상위 조합
- 개인전 카드 1장 제출
- 팀전 카드 1장 희생
- 내 라이프 표시
- 실시간 채팅
- 벨·카드·턴 연출
- 최종 결과 화면
- 다시하기 시 기존 방 대기실 복귀
- PC 기존 레이아웃

## 적용 방법

1. 압축을 풉니다.
2. 기존 `BELL-GAME` 폴더에 모든 파일을 덮어씁니다.
3. Live Server를 중지했다가 다시 실행합니다.
4. PC 브라우저에서 Ctrl + F5를 누릅니다.
5. GitHub에 업로드합니다.

```powershell
git add .
git commit -m "모바일 한 화면 UI 적용"
git push
```

## 아이폰에서 업데이트 확인

GitHub Pages 반영 후 홈 화면에 설치한 앱에서 예전 화면이 계속 보이면:

1. 앱을 완전히 종료
2. Safari에서 게임 주소 접속
3. 페이지 새로고침
4. 홈 화면 앱 다시 실행

그래도 이전 버전이면 기존 홈 화면 아이콘을 삭제한 뒤 Safari에서 다시 홈 화면에 추가합니다.
