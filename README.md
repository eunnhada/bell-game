# BELL 카드게임 Stage 10 — 초대 링크와 방장 승계

## 추가된 기능

- 대기실의 `초대 링크` 버튼
- 초대 링크 복사
- 휴대폰 기본 공유창
- 링크를 열면 방 코드 자동 입력
- 방장이 나가도 방이 삭제되지 않음
- 입장 순서가 가장 빠른 남은 플레이어에게 방장 자동 승계
- 마지막 플레이어가 나가면 방 자동 삭제
- 방장 변경 로그 표시

## 초대 링크 예시

```text
https://eunnhada.github.io/bell-game/?room=ABC123
```

친구가 링크를 열면 `ABC123`이 방 코드 입력란에 자동으로 들어갑니다.
닉네임만 입력하고 방 참가를 누르면 됩니다.

## 적용 방법

1. 압축을 풉니다.
2. 모든 파일을 기존 `BELL-GAME` 폴더에 덮어씁니다.
3. Live Server에서 Ctrl + F5로 테스트합니다.
4. GitHub에 업로드합니다.

```powershell
git add .
git commit -m "초대 링크와 방장 승계 추가"
git push
```

## 테스트

1. 방 생성
2. 다른 브라우저로 참가
3. 초대 링크 버튼 눌러 링크 복사
4. 새 시크릿 창에서 링크 열기
5. 방 코드 자동 입력 확인
6. 방장이 나가기
7. 남은 플레이어 중 한 명에게 방장 표시가 이동하는지 확인
