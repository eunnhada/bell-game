# BELL Stage 17 — 모바일 안정화 수정본

## 수정한 문제

### 벨 UI 깨짐

- 이전 벨 전용 스타일 충돌을 강제로 제거
- 오픈 카드·더미와 같은 3단 카드 구조로 고정
- 세로 글자나 잘린 글자가 나오지 않도록 writing-mode 초기화
- 벨 아이콘 영역 크기를 카드와 동일하게 맞춤

### 카드 버리기 버튼 잘림

- 내 카드 영역을 CSS Grid가 아닌 Flex 구조로 변경
- 손패가 남는 공간만 사용
- 카드 버리기 버튼은 항상 하단에 38~40px 확보
- 제출 버튼 영역도 고정 높이 확보

### 로그·채팅 펼치기

- 펼친 패널을 게임판 내부 계산 위치가 아닌 화면 고정 오버레이로 변경
- 화면 아래에서 독립적으로 표시
- 게임 화면에 가려지지 않음
- 로그와 채팅 내용에 자체 스크롤 적용
- 빠른 채팅과 입력창은 하단에 유지

### 가로 화면

- 픽셀 최소 너비를 제거
- 상대 14% / 필드 52% / 내 카드 34%로 배치
- 화면 폭을 넘는 가로 스크롤 제거
- 카드 크기를 화면 높이에 맞게 축소
- 로그 패널도 화면 안쪽에 배치
