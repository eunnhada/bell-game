# BELL v27 — 오픈 카드 손패 표시 수정

스크린샷의 로그를 확인하면 오픈 카드는 손패에 들어갔지만,
버리기 제한 시간이 지나 자동으로 한 장이 버려져 다시 4장이 된 상태였습니다.

## 수정 내용

- 카드 획득 후 버리기 제한시간 15초 → 25초
- 오픈 카드 획득 성공 안내
- 더미 카드 획득 성공 안내
- 버리기 단계에서 현재 손패 수 표시
- 새로 받은 카드에 NEW 표시
- 새 카드 금색 테두리 및 점멸 효과
- 5장 상태에서도 모든 카드가 보이도록 손패 영역 수정
- 모바일에서는 손패 가로 스크롤 지원
- 버리기 완료 후 NEW 표시 제거
- 자동 진행 요청 키에 턴 시작시간 포함

## 정상 흐름

1. 오픈 카드 또는 더미 클릭
2. 손패가 4장 → 5장
3. NEW 표시된 카드 확인
4. 25초 안에 버릴 카드 1장 선택
5. 선택한 카드 버리기 버튼 클릭
6. 다시 4장이 되고 다음 턴 진행
