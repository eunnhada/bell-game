# BELL v25 기능 통합 업데이트

## 규칙 변경

- 벨을 잘못 누른 사람만 라이프 2개 감소
- 예: 22점 플레이어가 벨을 누르고 상대가 23점·21점이면
  - 벨 누른 사람: 라이프 -2
  - 23점: 유지
  - 21점: 유지

## 라운드 승점

매 라운드 종료 시:
- 1위: +2점
- 2위: +1점
- 나머지: +0점

최종 순위는 누적 승점이 높은 순서입니다.
동점이면 기존 라운드 승리 수와 잔여 라이프로 비교합니다.

## 추가 기능

- 방장이 3라운드/5라운드 선택
- 나가기 전 확인창
- 나간 플레이어 턴 자동 스킵
- 내 차례 효과음
- 카드 획득 시 해당 플레이어 쪽으로 이동 후 페이드아웃
- 더미/오픈 카드 가져오기 효과음
- 간단한 루프 BGM 및 ON/OFF
- 마지막 5초 타이머 효과음
- 결과에 카드 색상과 숫자 함께 표시
- 손패 카드 간격 확대
- 개인전 카드 한 장 제출 가능 유지
