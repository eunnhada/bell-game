# BELL Stage 16 — 모바일 전체화면 레이아웃

## 수정 사항

### 세로 화면

- 화면 위와 아래의 불필요한 빈 공간 제거
- 게임판이 아이폰 화면 높이를 전부 사용
- 상단바를 게임판 내부 최상단에 고정
- 상대·필드·로그·내 카드 순서로 한 화면에 고정
- 남는 높이는 내 카드 영역이 자동 사용

### 벨 UI

- 벨을 오픈 카드·더미와 같은 `pile-button` 구조로 변경
- 제목·카드 면·하단 문구의 세 줄 구조 통일
- 벨 카드 크기와 오픈 카드·더미 크기 동일

### 안내 문구

- 게임 안내 문구를 필드 아래에서 제거
- 내 상태와 내 카드 사이로 이동
- 카드를 보는 동안에도 안내가 항상 보임

### 가로 화면

- 상단바가 화면 밖으로 밀리지 않음
- 왼쪽 상대 / 가운데 필드 / 오른쪽 내 카드 구조
- 가로 스크롤 제거
- 로그·채팅은 가운데 필드 하단 접이식 패널
- 방향 전환 시 강제로 레이아웃 다시 계산

### PWA 업데이트

서비스 워커 캐시 버전을 변경했습니다.

```text
bell-game-v16-fullscreen
```

기존 홈 화면 앱에서도 새 파일을 다시 받도록 구성했습니다.

## 적용 방법

1. 압축을 풉니다.
2. 기존 `BELL-GAME` 폴더에 전부 덮어씁니다.
3. Live Server를 중지했다가 다시 실행합니다.
4. PC에서 Ctrl + F5
5. GitHub에 업로드합니다.

```powershell
git add .
git commit -m "모바일 전체화면과 벨 UI 수정"
git push
```

## 아이폰 확인

1. GitHub Pages 반영 후 Safari에서 게임 주소 새로고침
2. 홈 화면 앱 완전히 종료
3. 다시 실행
4. 세로 화면 확인
5. 가로 화면으로 회전
6. 다시 세로 화면으로 회전

배포 후 1~2분 이상 지났는데도 이전 화면이면 홈 화면 앱을 삭제하고 다시 추가하세요.
