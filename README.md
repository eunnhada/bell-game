# BELL Stage 13 — 게임 연출과 실시간 채팅

희생 연출은 포함하지 않았습니다.
희생 규칙 자체는 기존과 동일하게 유지됩니다.

## 추가된 연출

- 내 턴 배너
- 벨 화면 번쩍임
- 벨 화면 흔들림
- 카드가 손패에 들어오는 애니메이션
- 오픈 카드 변경 애니메이션
- 마지막 5초 타이머 펄스와 효과음
- 세트 생존 연출
- 라이프 감소 연출
- 기존 효과음과 진동 유지

## 실시간 채팅

- 같은 방 플레이어끼리 실시간 채팅
- 최대 80자
- 최근 메시지 50개 표시
- 내 메시지와 상대 메시지 구분
- 읽지 않은 메시지 숫자 표시
- 빠른 채팅
  - 좋아!
  - 잠깐!
  - 가자!
  - 아깝다!
- 채팅 새 메시지 효과음

## 적용 방법

1. 압축을 풉니다.
2. 기존 `BELL-GAME` 폴더에 모든 파일을 덮어씁니다.
3. Live Server를 중지했다가 다시 실행합니다.
4. 일반 창과 시크릿 창에서 Ctrl + F5를 누릅니다.
5. 반드시 새 방으로 테스트합니다.

## GitHub 반영

```powershell
git add .
git commit -m "게임 연출과 실시간 채팅 추가"

```

## 테스트 순서

1. 일반 창에서 방 만들기
2. 시크릿 창에서 참가 및 준비
3. 게임 시작
4. 채팅 탭에서 메시지 전송
5. 다른 창에서 실시간 수신 확인
6. 내 턴 배너 확인
7. 카드 뽑기와 오픈 카드 변경 애니메이션 확인
8. 벨 연출 확인
9. 마지막 5초 효과 확인
