# BELL Stage 14 모바일 방향 전환 수정본

## 수정한 문제

- 세로 화면에서 상대 카드 영역이 지나치게 길어지던 문제
- 필드와 내 카드 사이에 큰 빈 공간이 생기던 문제
- 가로 화면 전환 후 다시 세로로 돌아오면 레이아웃이 깨지던 문제
- iPhone Safari/PWA 주소창 높이 변화 때문에 화면 높이가 잘못 계산되던 문제
- 로그·채팅 패널 확장 후 위치가 어긋나던 문제

## 수정 방식

- `100dvh`만 사용하지 않고 실제 `visualViewport.height`를 CSS 변수로 전달
- 방향 전환 직후 높이를 여러 번 다시 측정
- 세로 화면의 네 영역 높이를 제한
- 상대 카드 최대 높이 제한
- 필드 높이 제한
- 손패 영역 최소·최대 높이 지정
- 세로 화면의 가로 권장 팝업 제거
- 가로 화면과 세로 화면 레이아웃을 완전히 분리

## 적용 방법

1. 압축을 풉니다.
2. 기존 `BELL-GAME` 폴더에 전부 덮어씁니다.
3. Live Server를 중지했다가 다시 실행합니다.
4. PC에서 Ctrl + F5
5. GitHub에 업로드합니다.

```powershell
git add .
git commit -m "모바일 방향 전환 화면 수정"
git push
```

## 아이폰 테스트

1. Safari에서 배포 주소를 직접 열어 새로고침
2. 홈 화면 앱 완전히 종료
3. 다시 실행
4. 세로 → 가로 → 세로 전환
5. 상대 영역, 필드, 로그, 손패가 정상적으로 돌아오는지 확인

PWA가 이전 CSS를 계속 보여주면 홈 화면 아이콘을 삭제하고 Safari에서 다시 추가하는 것이 가장 확실합니다.
