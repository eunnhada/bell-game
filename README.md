# BELL 카드게임 Stage 12 — 모바일·접근성 최적화

## 추가된 기능

- 색상 구분 기호
  - 빨강 R
  - 노랑 Y
  - 초록 G
  - 파랑 B
- 큰 글씨 모드
- 애니메이션 줄이기
- 게임 중 화면 꺼짐 방지
- 전체화면 버튼
- 세로 휴대폰에서 가로 화면 권장 안내
- 설정을 브라우저에 저장
- 설정은 다음 접속에도 유지

## 적용 방법

1. 압축을 풉니다.
2. 기존 `BELL-GAME` 폴더에 모두 덮어씁니다.
3. Live Server에서 Ctrl + F5로 확인합니다.
4. 정상 작동하면 GitHub에 업로드합니다.

```powershell
git add .
git commit -m "모바일 접근성 설정 추가"
git push
```

## 휴대폰 테스트

1. 게임 설정 열기
2. 색상 구분 기호 켜기
3. 카드 좌측 위 R·Y·G·B 확인
4. 큰 글씨 켜기
5. 애니메이션 줄이기 켜기
6. 게임 시작 후 전체화면 버튼 확인
7. 화면을 세로로 두었을 때 가로 권장 안내 확인

## 참고

화면 꺼짐 방지 기능은 브라우저와 기기에서 Screen Wake Lock API를 지원할 때만 작동합니다.
iPhone 일부 환경에서는 전체화면 버튼이 제한될 수 있으며, 홈 화면에 설치한 PWA로 실행하면 더 앱처럼 사용할 수 있습니다.
