# BELL 최종 결과 및 다시하기 수정본

## 수정 내용

### 최종 결과 화면 유지

- 5라운드가 끝나도 메인 화면이나 대기실로 자동 이동하지 않음
- 최종 순위와 결과 화면이 계속 표시됨
- 사용자가 버튼을 누를 때까지 결과 화면 유지

### 다시하기

- 결과 화면에서 `다시하기` 클릭
- 새 방을 만들지 않음
- 기존 방 코드와 참가자 유지
- 참가했던 방의 대기실로 전원 이동
- 라이프 5개 초기화
- 라운드·세트 기록 초기화
- 방장만 준비 상태
- 나머지 플레이어는 다시 준비 버튼을 눌러야 함
- 기존 게임 모드와 팀 정보 유지

### 메인으로 나가기

- 결과 화면의 `메인으로 나가기`는 기존처럼 방을 나가고 메인 화면으로 이동

## 적용 방법

1. 압축을 풉니다.
2. 기존 `BELL-GAME` 폴더에 모든 파일을 덮어씁니다.
3. Live Server를 중지했다가 다시 실행합니다.
4. 일반 창과 시크릿 창에서 Ctrl + F5를 누릅니다.
5. 반드시 새 방으로 테스트합니다.

## GitHub 반영

```powershell
git add .
git commit -m "최종 결과와 다시하기 대기실 복귀 수정"
git push
```

## 테스트

1. 5라운드 종료
2. 최종 결과 화면이 유지되는지 확인
3. 다시하기 클릭
4. 같은 방 코드의 대기실로 이동하는지 확인
5. 방장은 준비, 나머지는 대기 상태인지 확인
6. 전원이 준비한 뒤 다시 게임 시작
