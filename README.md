# BELL v22 — 입력창·가로 배치 수정

## 수정 내용
- 가로 중앙 오픈 카드·더미·벨 크기와 위치 재조정
- 가로 내 패 카드 전체가 하단에 보이도록 축소 및 여백 확보
- 채팅 입력창 포커스 시 iPhone 자동 확대 방지
- 채팅 키보드가 올라오면 채팅창을 화면 위쪽에 유지
- 홈 닉네임·방 코드 입력 시 화면 잘림 방지
- 방 코드 입력창을 포커스하면 화면 상단 쪽으로 자동 이동
- 좌측 상단에 현재 버전 `v22` 표시

## 적용
```powershell
git add .
git commit -m "v22 입력창과 가로 카드 배치 수정"
git push
```
