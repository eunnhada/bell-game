# BELL Stage 18 — Layout Reset

기존 모바일 CSS가 여러 단계 누적되어 충돌하던 부분을 강제로 분리한 버전입니다.

## 핵심 수정

### 벨

- 벨 전용 `span` 구조 제거
- 일반 카드와 동일한 `.card` 요소로 교체
- 오픈 카드·더미와 동일한 크기
- PC와 모바일에서 세로 글자·과도한 확대 문제 차단

### 가로 화면

- 게임 중 `.app` 바깥 레이아웃까지 화면에 고정
- 상단 46px / 본문 / 로그바 38px 구조
- 상대 13% / 필드 53% / 내 카드 34%
- 페이지 자체 위아래 스크롤 차단
- 로그바도 Grid 안에 포함

### 로그·채팅

- 펼치면 화면 중앙 독립 창
- 게임판 배치와 무관하게 표시
- 메시지 목록만 내부 스크롤
- 입력창과 빠른 채팅은 하단 고정

### 카드 버리기

- 손패 영역을 Flex로 강제
- 카드 목록만 남는 공간 사용
- 버리기·제출 버튼은 항상 하단 공간 확보
