# BELL Stage 15 Mobile Rebuild

모바일 세로·가로 화면을 완전히 분리해 새로 구성한 버전입니다.

## 세로 화면

- 상대 영역 고정 72px
- 게임 필드 고정 204px
- 로그·채팅 고정 42px
- 나머지 공간은 내 카드가 사용
- 상대 카드가 세로로 늘어나는 문제 제거
- 큰 빈 공간 제거
- 내 카드가 항상 화면 안에 표시

## 가로 화면

- 왼쪽: 상대 플레이어
- 가운데: 오픈 카드·더미·벨
- 오른쪽: 내 라이프·내 카드
- 로그·채팅은 우측 하단 접이식 패널

## 방향 전환

- 가로→세로 또는 세로→가로 전환 시 화면 높이 재측정
- 0.12초·0.32초·0.62초 후 추가 재계산
- 스크롤 위치 초기화
- 열린 로그·카드 확대창 자동 닫기
- 앱을 다시 열었을 때도 화면 재계산

## 유지 기능

- 포카드
- 개인전 한 장 제출
- 팀전 한 장 희생
- 내 라이프 표시
- 실시간 채팅
- 카드·벨·턴 연출
- 최종 결과 화면
- 다시하기 시 같은 방 대기실 복귀
- PC 화면 유지

## 적용 방법

1. 압축을 풉니다.
2. 기존 `BELL-GAME` 폴더에 전부 덮어씁니다.
3. Live Server를 중지했다가 다시 실행합니다.
4. PC에서 Ctrl + F5
5. GitHub에 업로드합니다.

```powershell
git add .
git commit -m "모바일 세로 가로 UI 전면 재구성"
git push
```

## 아이폰에서 꼭 할 것

1. GitHub Pages 반영 후 Safari에서 게임 주소를 직접 열기
2. Safari 페이지 새로고침
3. 기존 홈 화면 BELL 앱 삭제
4. Safari 공유 → 홈 화면에 추가
5. 새로 설치한 앱에서 테스트

기존 홈 화면 앱은 이전 서비스 워커와 CSS를 오래 보관할 수 있어 삭제 후 재설치가 가장 확실합니다.
