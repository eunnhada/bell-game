# BELL Stage 19 — Compact UI

화면 겹침의 원인이었던 큰 카드·큰 글씨·큰 여백을 전체적으로 축소한 버전입니다.

## 주요 변경

- 벨을 완전히 독립된 `compact-pile-button`으로 교체
- 기존 벨 CSS의 세로 글자 영향 차단
- 오픈 카드·더미·벨 크기 통일
- 전체 텍스트 크기 축소
- 상대 카드·타이머·상단 버튼 축소
- 내 상태·라이프·안내 문구 축소
- 손패 카드 크기 축소
- 로그 바와 채팅 UI 축소
- 가로 화면을 11% / 55% / 34%로 재배치
- 가로 상단 40px, 로그 바 32px
- 게임 페이지 자체 스크롤 차단

## 적용
