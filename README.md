# BELL v23 — 카드 크기 통일 및 손패 수정

## 수정 내용

- 가로 화면 오픈 카드·더미·벨 실제 카드 크기를 56×78px로 완전 통일
- 중앙 필드 전체 크기 축소
- 세 개 UI의 제목·카드·하단 문구 높이 통일
- 가로 내 패 카드 크기 축소
- 내 패 영역 높이와 하단 패딩 확대
- 카드 아랫부분 잘림 방지
- 카드 선택 시 올라가는 높이 축소
- 내 라이프 하트를 닉네임 오른쪽에 고정
- 버전 `v23`은 메인 화면에서만 표시
- 게임 화면과 대기실에서는 버전 숨김
