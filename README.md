# BELL Stage 12 준비 버튼 오류 수정본

Stage 13 기능은 포함하지 않습니다.

## 수정 내용

- 준비 버튼 이벤트가 대기실 렌더링 함수 안에서 반복 등록되던 오류 수정
- 준비 버튼 이벤트를 한 번만 등록
- 준비 처리 중 연속 클릭 방지
- 팀 다시 섞기와 강퇴 버튼의 중복 실행 방지
- 오류 발생 시 대기실에 오류 메시지 표시

## 적용 방법

1. 압축을 풉니다.
2. 기존 `BELL-GAME` 폴더에 전부 덮어씁니다.
3. Live Server를 중지했다가 다시 실행합니다.
4. 브라우저에서 Ctrl + F5를 누릅니다.
5. 기존 방이 아닌 새 방을 만듭니다.
6. 시크릿 창에서 방에 참가한 뒤 준비하기를 누릅니다.
