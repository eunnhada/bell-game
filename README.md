# BELL Stage 20 — Table UI

가로 화면을 포커 게임처럼 테이블 중심 UI로 변경한 버전입니다.

## 가로 화면 배치

- 상단: 라운드·세트·타이머·나가기
- 테이블 위쪽: 상대 프로필 최대 3명
- 테이블 좌우: 상대 프로필 최대 2명
- 중앙: 오픈 카드·더미·벨
- 하단: 내 상태·안내 문구·내 카드·버리기/제출 버튼
- 최하단: 로그·채팅 바

## 상대 턴 네모 타이머

상대 차례가 되면 해당 상대 프로필 옆에 네모 타이머가 표시됩니다.

- 남은 초 숫자 표시
- 시간이 줄어들수록 테두리 게이지 감소
- 5초 이하에서는 빨간색
- 현재 턴 상대 프로필 금색 강조

## 유지되는 기능

- 세로 Compact UI
- 포카드
- 개인전 카드 1장 제출
- 팀전 카드 1장 희생
- 실시간 채팅
- 로그·채팅 중앙 팝업
- 최종 결과 및 다시하기
