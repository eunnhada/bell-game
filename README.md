# BELL 내 라이프 표시 및 1장 제출 수정본

이 버전은 Stage 13 채팅·연출 버전을 기준으로 수정했습니다.

## 수정 내용

### 내 라이프 표시

- 내 카드 바로 위에 `내 상태` 영역 추가
- 내 닉네임 표시
- 내 라이프를 큰 하트로 표시
- 라이프 감소 시 하트 애니메이션
- 라이프 0이면 `라이프 0 · 탈락` 표시

### 카드 1장 제출

- 개인전:
  - 카드 1장 제출 가능
  - 카드 숫자가 그대로 점수
  - 예: 파랑 8 한 장 제출 = 8점

- 팀전:
  - 카드 1장 제출 가능
  - 기존 규칙대로 희생 제출로 처리
  - 본인 라이프 1개 감소
  - 최저 점수 팀원 보호

- 카드 2장 이상:
  - 기존과 동일
  - 같은 색 또는 같은 숫자 조합만 가능

## 적용 방법

1. 압축을 풉니다.
2. 기존 `BELL-GAME` 폴더에 모든 파일을 덮어씁니다.
3. Live Server를 중지했다가 다시 실행합니다.
4. 일반 창과 시크릿 창 모두 Ctrl + F5를 누릅니다.
5. 반드시 새 방으로 테스트합니다.

## GitHub 반영

```powershell
git add .
git commit -m "내 라이프 표시와 한 장 제출 추가"
git push
```

## 테스트

1. 게임 시작 후 내 카드 위에 내 라이프가 보이는지 확인
2. Firebase에서 내 life 값을 낮춰 하트 수 변경 확인
3. 개인전에서 카드 1장만 선택해 제출
4. 선택한 숫자가 점수로 계산되는지 확인
5. 팀전에서 카드 1장 제출 시 희생으로 처리되는지 확인
