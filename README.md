# BELL v24 — 중앙 카드 정렬 수정

## 수정 내용

- 가로 화면 중앙의 오픈 카드·더미·벨 외부 박스 높이 통일
- 세 박스를 동일한 3단 구조로 고정
  - 제목 18px
  - 카드 슬롯 98px
  - 하단 문구 14px
- 실제 카드 크기를 60×88px로 완전 통일
- 작은 가로 화면에서는 54×78px로 자동 축소
- 카드가 박스 아래로 잘리는 문제 수정
- 더미 카드 수가 카드 위에 겹치는 문제 수정
- 벨 아이콘과 오픈 카드 숫자의 수직 중심 정렬
- 버전은 메인 화면에서만 v24 표시
