# BELL Stage 21 — 턴 타이머와 중앙 필드 수정

## 타이머

- 내 차례: 우측 상단 원형 타이머 표시
- 상대 차례: 우측 상단 원형 타이머 숨김
- 상대 차례에는 해당 상대 프로필 테두리가 타이머처럼 감소
- 프로필 우측 상단에 남은 초 표시
- 5초 이하 빨간색

## 중앙 카드 UI

- 가로 화면 타원형 테이블 제거
- 중앙에 오픈 카드·더미·벨을 같은 크기로 수평 배치
- 전체 중앙 필드 크기 축소
- 카드 위치와 잘림 개선

## 로그·채팅

- 가로 화면 하단에 로그·채팅 버튼 항상 표시
- 펼치기 버튼과 효과음 버튼 유지
- 펼치면 중앙 팝업

## 세로 상대 타이머

- 상대 프로필 카드 내부에 남은 초 표시
- 타이머가 화면 밖으로 잘리지 않도록 수정
