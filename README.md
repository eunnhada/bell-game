# BELL v25-audited

v25-fixed의 10가지 요구사항을 코드 기준으로 다시 대조하고 보완한 버전입니다.

## 검증 결과

1. 잘못 벨을 누르면 벨을 누른 사람만 라이프 -2: 적용
2. 손패 간격 확대 및 터치 영역 안정화: 적용
3. 방 설정 3라운드/5라운드: 적용
4. 나가기 예/아니오 확인: 적용
5. 나간 플레이어 턴 자동 스킵: 적용
6. 내 차례 효과음: 적용
   - 게임 시작 직후 첫 차례인 경우도 재생
7. 카드가 획득 플레이어 쪽으로 이동하며 페이드아웃: 새로 적용
8. 더미/오픈 카드 획득 시 쓱 효과음: 새로 강화
9. BGM 및 ON/OFF: 적용
10. 내 턴·상대 턴 모두 마지막 5초 타이머음: 적용
